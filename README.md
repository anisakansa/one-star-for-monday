# One Star for Monday

make.fun entry for [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

The program writes one line to `output/entry.txt` — a one-star review of Monday, written as if Monday were a restaurant:

> One star. Booked a table for the weekend, got seated on Monday instead, and the waiter charged me five days.

The joke: you booked the weekend and got seated on Monday instead — and the bill is the whole work week. Only Monday directly follows a weekend booking, so the line could not be about any other day.

Run with Node 22: `node main.ts`. The output is a constant string with deterministic gates (108 characters, 20 words, one line, pure ASCII, no trailing newline), so repeated runs are byte-identical.
